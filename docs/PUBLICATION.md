# Public snapshot — 5 November 2026

The public repository combines the current local research software, methods, selected benchmark evidence and instrument designs in the existing root-level Python layout. The local vault uses a different folder layout; public links were adjusted where needed.

## Included

- Python package, CLI, configurations, experiment scripts and existing software tests.
- Model architecture/method reports and selected lightweight run reports, metrics, protocols, frozen selections and audits.
- An anonymized research-discussion README, with verified links to the five cited PDB entries.
- Doser parts/wiring/tubing documentation, supplier workbook, diagram/Blender generators and visual assets.
- Olfactometer design and analytical utility code.
- Literature atlas collection/screening code and research methods, plus ligand-based pharmacophore prototype code and calculated outputs.

## Excluded or sanitized

Personal correspondence and attachments, contact compilations, meeting availability/access details, legal/company records, credentials, local worktrees and private hosting receipts are excluded. Research passages relying on private author replies were removed from public copies. Raw/downloaded source documents, full literature databases, trained weights, model caches and bulk data are excluded. Local account paths and private host identities were replaced with placeholders.

Selected evidence records are not complete trained model bundles. Source-code hashes refer to the original recorded calculations; path sanitization and portable launcher changes do not reproduce or revalidate those calculations. Scientific metrics were not changed by the export. Guarded research scripts use the explicitly configured `CALNEW_COMPUTE_HOST` environment variable in place of a private hardcoded hostname, and Windows launchers use their own checkout location and the active Python environment.

The earlier contact-oriented literature compilation and researcher contact list were removed from the current public tree. This update does not rewrite earlier Git history.

## Verification boundary

Verification for this export covers publication privacy screening, text/JSON/canvas parsing, Python syntax and the reviewed Git file set. Numerical model fitting, inference and tests remain restricted to the authorized remote compute environment. Historical reports of passing numerical tests are retained as historical evidence, not represented as a new run for this publication.

The reviewed snapshot contains 577 files, approximately 30 MB. Static checks parsed 163 Python files, 251 JSON/canvas files and nine SVGs, checked the supplier workbook archive and verified the local Markdown links. The core package, existing tests and configurations match the local source snapshot byte for byte. PNG metadata containing local paths was removed while retaining the original compressed pixel data.

Third-party data and dependencies retain their source-specific conditions. The publication does not grant new rights to omitted datasets or to third-party materials referenced by the research reports.
