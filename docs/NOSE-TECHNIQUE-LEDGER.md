## How to read the evidence

- **Executed, artifact-backed:** a completed report, results file, prediction file, or fitted-model manifest establishes execution. The link points to the evidence, not merely to an implementation.
- **Executed, historical exploratory:** retained predictions or fitted-feature caches support execution, but the early selection protocol has weaker nesting or incomplete provenance. Those results must not be presented as equivalent to later fully nested experiments.
- **Documented outcome:** a workspace report records execution and an outcome, but an independently inspectable per-candidate result artifact was not located in this audit.
- **Source only:** code exists, but neither completed execution nor a numerical outcome was established. A script's existence is not evidence that it ran.
- **Stopped before fitting:** setup or an invariant check failed before model fitting. This is recorded separately from a completed unsuccessful model.

All numerical values below were read from existing artifacts or reports; this audit did not recompute scores. `runs/` and `data/` are ignored by Git, so these links depend on the retained workspace artifacts. The historical temporary evidence described at the end is less durable.
